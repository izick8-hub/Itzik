# Exercise catalog and photographs

Source: https://github.com/yuhonas/free-exercise-db
Dataset: https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json
Retrieved: 2026-11-02

The upstream README describes the project as an “Open Public Domain Exercise Dataset” and labels its license as Unlicense. It explicitly supports local use of JSON files and images and hosted image URLs. This app retains identifiers, names, muscle groups, equipment, and image paths from 876 records. 873 original catalog photographs were retrieved and verified on 2026-11-04 and are served from public/exercise-photos. Their source paths remain documented in src/exercises.json, with local filenames in src/photo-files.json.
